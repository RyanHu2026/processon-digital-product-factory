# ProcessOn 图形产品批量生产工具

这是一个运行在 Windows 本地的 AI 图形内容生产工具，用来把多个主题批量生成可导入 ProcessOn 的结构图文件。

项目以 ProcessOn 原生 `.pos` 为主输出格式。只有选择“思维导图”时才额外生成 `.xmind`；流程图、鱼骨图、树状结构图、双边思维导图和组织结构图不会生成 XMind，避免被 ProcessOn 的 XMind 导入器重新排成单边思维导图。

## 主要用途

- 批量输入多个学习或工作主题
- 调用 DeepSeek 等 OpenAI 兼容模型生成结构化内容
- 根据所选图形类型生成不同布局
- 自动检查节点数量、层级、空节点和重复节点
- 输出 ProcessOn 原生 POS 文件
- 保存结构化 JSON、质量报告和发布资料
- 使用 SQLite 保存本地任务和批次记录
- 在网页中查看文件路径或打开存储位置

## 支持的图形类型

| 图形类型 | 主要结构 | 输出文件 |
|---|---|---|
| 思维导图 | 中心主题向左右展开 | POS + XMind |
| 流程图 | 开始、处理、判断、结束及连线 | 仅 POS |
| 鱼骨图 | 主问题、原因类别、子原因 | 仅 POS |
| 树状结构图 | 根节点向右逐层展开 | 仅 POS |
| 双边思维导图 | 中心主题左右双向展开 | 仅 POS |
| 组织结构图 | 上级、部门、下属单元 | 仅 POS |

除“思维导图”外，其他类型坚决不生成 XMind。

## 当前功能

- 中文本地 Web 工作台
- 批量添加主题、领域分类、目标读者、难度和图形类型
- 图形类型与难度选择持久保存，刷新页面不会自动重置
- OpenAI 兼容 Chat Completions 接口
- DeepSeek 默认接口配置
- API Key 保存到 Windows Credential Manager
- API Key 不写入源码、SQLite、日志或导出文件
- 演示模式用于离线测试完整生成流程
- 单主题失败不影响同批次其他主题
- 批次名称使用“时间 + 主题名称”
- 批次 ZIP 本地归档
- 查看文件路径和打开存储位置
- 旧任务可重新生成

## 难度规则

| 难度 | 节点数量 | 最大层级 |
|---|---:|---:|
| 基础 | 20–80 | 3 层 |
| 标准 | 30–140 | 4 层 |
| 进阶 | 60–240 | 4 层 |

模型可能偶尔超过预算，因此程序还会自动处理：

- 节点超过上限：优先保留一级分支和浅层内容，自动裁剪末端节点
- 层级超过上限：把过深路径合并到允许的最大层级
- 处理记录会写入质量说明，不会直接让整个主题失败

## 启动方法

### 方法一：双击启动

1. 确保电脑已安装 Python 3.11 或更高版本。
2. 双击项目目录中的 `start.bat`。
3. 浏览器访问：

```text
http://127.0.0.1:4174
```

4. 如果页面还是旧版本，按 `Ctrl + F5` 强制刷新。

### 方法二：PowerShell 启动

```powershell
python app.py
```

## 模型配置

默认配置：

```text
API Base URL：https://api.deepseek.com
模型 ID：deepseek-chat
```

第一次使用真实模型时：

1. 取消勾选“演示模式”。
2. 填写 API Key。
3. 点击模型测试。
4. 测试通过后开始生成。

API Key 会保存到 Windows Credential Manager，后续启动不用重复填写，页面也不会回显完整 Key。

程序不提供“最大输出 Token”输入框，使用模型服务商的默认策略，并通过节点预算做二次控制。

## 使用流程

1. 打开“批量生成”。
2. 每行输入一个主题。
3. 选择领域分类和目标读者。
4. 选择图形类型。
5. 选择基础、标准或进阶难度。
6. 点击“加入任务”。
7. 检查图形类型没有被重置。
8. 点击“开始生成”。
9. 在工作台查看生成状态。
10. 点击“查看文件路径”或“打开存储位置”。
11. 在 ProcessOn 中优先导入 `.pos` 文件。

## 输出文件

每个主题的输出目录包含：

```text
主题名称.pos                 ProcessOn 原生图形文件
主题名称.xmind               仅思维导图生成的兼容文件
content.json                 模型生成的结构化内容
quality-report.json          节点数量、层级和质量检查结果
publish-materials.json       标题、简介、关键词和售价参考
```

输出位置：

```text
data/outputs/批次名称/主题名称/
```

本地数据库位置：

```text
data/factory.sqlite3
```

`data/` 中的数据库和生成结果不会上传到 GitHub。

## ProcessOn 导入说明

优先使用 `.pos`：

1. 在 ProcessOn 中选择导入文件。
2. 选择单个 `.pos` 文件。
3. 不要直接选择批次 ZIP。
4. ZIP 只用于本地归档，需要先解压。

XMind 只作为普通思维导图的兼容备份。流程图、鱼骨图、树状结构图、双边思维导图和组织结构图不输出 XMind。

## 常见问题

### 页面还是旧版本

关闭旧的命令窗口，重新运行 `start.bat`，然后在浏览器按 `Ctrl + F5`。

### 打开存储位置提示不存在

确认本地服务已经重启。新版本会修正重复拼接 `data/outputs` 的问题，并让数据库路径指向实际 POS 文件。

### 标准版本节点超过 140

程序会自动裁剪到 140 个以内，并在质量说明中记录裁剪数量，不再直接判定整个任务失败。

### 标准版本显示五层超过四层

程序已经修复空 `children` 被多计算一层的问题。真正超过四层时会自动压平到四层。

### 选择鱼骨图或树状图却显示为思维导图

图形类型现在保存在浏览器本地状态中。加入任务后不会自动重置。开始生成前检查提示文字是否显示当前选择；非思维导图只会输出 POS。
